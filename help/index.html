VPN включён, а интернета нет

  1. Выберите сервер «Автопилот» — он сам найдёт рабочий.
  2. Обновите подписку: кнопка ↻ в карточке подписки внизу главного экрана.
  3. Проверьте, не закончилась ли подписка — срок виден в той же карточке.
  4. Выключите и снова включите VPN (нажмите на щит два раза).

Если вверху приложения висит баннер о сбое или техработах — мы уже чиним, автопилот сам переключит на рабочий сервер.

На мобильном интернете ничего не открывается

Скорее всего, оператор включил белые списки — пускает только на «разрешённые» сайты.

  • Выберите «Автопилот»: он заметит белые списки и сам перейдёт на LTE-обход, а когда ограничения снимут — вернётся обратно.
  • Автопереход можно включить или выключить: Настройки → Профиль.
  • LTE-обход обычно с лимитом трафика — включайте его только когда обычные серверы не работают.

VPN сам отключается

  1. Разрешите работу в фоне: настройки телефона → Приложения → APEX CLIENT → Батарея → Без ограничений (на разных телефонах пункт называется чуть по-разному).
  2. Не закрывайте APEX CLIENT смахиванием, если телефон после этого «убивает» приложения (часто бывает на Xiaomi, Huawei, Honor).
  3. Если включён другой VPN — Android отключит APEX. Включайте только один.

Если VPN отключится или не сможет подключиться, приложение пришлёт уведомление с кнопкой «Подключить снова».

Банк, Госуслуги или маркетплейс не открываются

  • В умном режиме российские сайты и приложения идут напрямую, без VPN.
  • Приложение ругается на VPN — добавьте его в «Скрыть VPN»: оно будет работать напрямую и не увидит VPN.

Как обновить

Приложение само проверяет обновления и предлагает поставить новую версию. Проверить вручную: Настройки → Обновления. Можно также скачать файл с главной страницы и установить поверх — настройки и подписка сохранятся.

Подробно по шагам: телефон, ТВ, часы

Android TV

  1. На телевизоре откройте браузер (или файловый менеджер) и скачайте тот же файл, что для телефона — с главной страницы.
  2. Разрешите установку из этого приложения, когда телевизор спросит.
  3. Добавьте подписку. Удобнее всего — ссылкой-приглашением: сделайте её на странице «Пригласить друга» и откройте на телевизоре.
  4. Управление с пульта: OK на щите включает VPN, стрелками выбирается страна.

Часы Wear OS

  • Для часов — отдельный файл apex-watch-….apk (кнопка «Скачать для часов» на главной). На телефон его не ставьте.
  • На телефоне должен стоять и работать APEX CLIENT — часы управляют им: включить VPN, выбрать страну, посмотреть пинг.

Не устанавливается

  • Android спросит разрешение на установку из браузера — разрешите один раз.
  • «Приложение не установлено» — удалите старую версию, если она скачана не с нашего сайта или GitHub, и поставьте заново.
  • Нужен Android 7 или новее.

Каждая версия собирается на GitHub из открытого кода и подписана одним ключом. Приложение само проверяет, что это оригинал, и предупредит, если копию подменили.

Настройка под ваш телефон

Чтобы APEX ставился без ошибок и не отключался в фоне. Названия пунктов на разных версиях прошивки чуть отличаются.

⬇️Установка: откройте скачанный файл → «Настройки» → включите «Разрешить установку из этого источника» → назад → «Установить».
🔋Батарея: Настройки → Приложения → Все приложения → APEX CLIENT → Контроль активности → Нет ограничений.
🚀Автозапуск: там же, в карточке APEX CLIENT → включите Автозапуск.
🔒Закрепить: откройте недавние приложения, зажмите APEX CLIENT → значок замка. Тогда «Очистить всё» его не закроет.
⬇️Установка: откройте файл → «Настройки» → разрешите «Установка неизвестных приложений» для браузера или «Мои файлы».
🔋Батарея: Настройки → Приложения → APEX CLIENT → Батарея → Без ограничений.
💤Спящие приложения: Настройки → Обслуживание устройства (Батарея) → Ограничения в фоновом режиме → уберите APEX CLIENT из «Спящих» и «Глубоко спящих».
⬇️Установка: откройте файл → разрешите установку из этого источника. Если телефон предлагает «проверку безопасности» — пропустите её для APEX.
🔋Запуск приложений: Настройки → Батарея → Запуск приложений → APEX CLIENT → выключите «Автоматическое управление» и включите все три переключателя.
🔒Закрепить: в недавних приложениях потяните карточку APEX CLIENT вниз — появится замок.
⬇️Установка: при открытии файла разрешите установку из браузера или файлового менеджера.
🔋Батарея: Настройки → Приложения → APEX CLIENT → Батарея → Без ограничений (или «Не оптимизировать»).
🛡Постоянный VPN: Настройки → Сеть → VPN → ⚙️ у APEX CLIENT → «Постоянная VPN» — Android будет держать VPN включённым сам.
Не помогло?

В приложении: Настройки → О приложении → «Написать в поддержку». Там же можно одной кнопкой отправить отчёт — без ссылки подписки, ключей и IP.
