    Установка за минуту

    Приложения нет в Google Play — оно скачивается файлом с GitHub, где лежит его открытый код.

    1. Скачайте файл

      Нажмите «Скачать для Android» — загрузится файл apex-client.apk.

    2. Разрешите установку

      Откройте файл. Android попросит разрешить установку из браузера — разрешите один раз.

    3. Вставьте подписку

      Откройте APEX CLIENT, вставьте ссылку подписки и нажмите на щит. Обновления дальше ставятся сами.

    Вопросы

    APEX VPN и APEX CLIENT — это одно и то же?

    Да. С версии 3.19.1 приложение называется APEX CLIENT — сменилось только название. Обновляется поверх, подписка и настройки остаются.

    Это бесплатно?

    Приложение бесплатное и с открытым кодом (лицензия GPL-3.0). Для работы нужна подписка — ссылка на ваши серверы.

    Откуда взять подписку?

    Её выдаёт сервис, к которому вы подключаетесь. Ссылку можно вставить вручную, отсканировать QR-код или открыть ссылку-приглашение.

    Безопасно ли ставить не из Google Play?

    Каждая версия собирается на GitHub из открытого кода и подписана одним ключом. Приложение само проверяет, что это оригинал, и предупредит, если копию подменили. Как отличить оригинал.

    Сайты не открываются при белых списках

    Выберите «Автопилот» — он сам найдёт LTE-обход. Если обход выбран вручную, весь трафик идёт через VPN, чтобы открывались и российские сайты.

    Куда писать, если что-то не работает?

    В приложении: Настройки → О приложении → «Написать в поддержку». Там же можно одной кнопкой отправить отчёт — без ссылки подписки, ключей и IP.
