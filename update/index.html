Как обновить

Обычно ничего делать не нужно: приложение само узнаёт о новой версии. Настройки и подписка при обновлении сохраняются.

Последняя версия — загружаем…Сравните с версией в «Настройки → О приложении»
Скачать
  1. Откройте настройки обновлений

    Приложение проверяет новые версии при запуске и раз в час. Проверить вручную:

    Настройки›Обновления
  2. Нажмите «Обновить»

    Приложение скачает новую версию с GitHub и проверит, что файл оригинальный.

  3. Подтвердите установку

    Android покажет окно «Обновить это приложение?» — нажмите «Обновить». Если спросит разрешение на установку из APEX CLIENT — разрешите один раз.

  4. Готово

    Откройте приложение и нажмите на щит. Что нового — в окне после обновления и на странице всех версий.

Не нравится новая версия? Настройки → Обновления → «Вернуть прошлую версию» — по шагам, настройки сохранятся.

  1. Откройте APEX CLIENT на телевизоре

    Приложение на ТВ тоже само проверяет обновления. Стрелками пульта перейдите в настройки:

    Настройки›Обновления
  2. Выберите «Обновить» и нажмите OK

    Телевизор скачает новую версию и спросит разрешение на установку — подтвердите.

  3. Если кнопки нет

    Откройте на телевизоре браузер, зайдите на dubstep2004.github.io, скачайте файл для телефона (он же для ТВ) и установите поверх — подписка останется.

Подробнее про телевизор — в Помощи.

  1. Сначала обновите телефон

    Часы обновляются с телефона — отдельно скачивать ничего не нужно.

  2. Передайте обновление на часы

    Если часы отстали, на телефоне появится кнопка:

    Настройки›Обновления›Обновить часы APEX Watch
  3. Нажмите «Установить» на часах

    Телефон сам скачает версию для часов, проверит её и отправит. На часах останется одна кнопка.

Файл apex-watch-….apk — только для часов. На телефон его не ставьте.

  1. Включите «Ставить само»
    Настройки›Обновления›Ставить само
  2. Всё остальное — без вас

    Новая версия скачается заранее и поставится, когда VPN выключен или экран погас.

  3. Бережёте мобильный трафик?

    Включите там же «Скачивать только по Wi-Fi».

Хотите новые версии раньше всех — «Бета-версии» в том же разделе. Они могут быть сырыми.

Не обновляется?

«Приложение не установлено» — удалите копию, скачанную не с нашего сайта или GitHub, и поставьте заново.
