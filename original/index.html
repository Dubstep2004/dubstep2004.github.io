Как отличить оригинал

APEX CLIENT скачивается только с GitHub или с этого сайта. Подделки могут красть подписку или показывать рекламу — проверить оригинал можно за минуту.

Где скачивать

  • Сайт: dubstep2004.github.io — кнопка «Скачать».
  • GitHub: github.com/Dubstep2004/apex-client → Releases.
  • Внутри приложения: обновления приходят сами, с того же GitHub.

⚠️ Других официальных сайтов, ботов с файлами и «модов» нет. APEX CLIENT бесплатный — если за приложение просят деньги, это подделка.

Проверка в приложении

Откройте Настройки → О приложении. Внизу должно быть написано «✓ Официальная сборка».

Если там «⚠ Неофициальная копия» — приложение подписано чужим ключом. Удалите его и скачайте заново с этого сайта. Подписку лучше перевыпустить.

Отпечаток подписи

Все официальные версии подписаны одним ключом. Его отпечаток SHA-256:

61:15:D6:55:A0:8D:FE:7C:97:0B:E7:DF:C1:1E:06:E3:5F:7E:C8:B8:BD:78:FF:5A:B7:82:F6:51:45:B1:00:D4

Проверить на компьютере (нужен Android SDK): apksigner verify --print-certs apex-vpn-….apk — строка «SHA-256 digest» должна совпасть (без двоеточий, регистр не важен).

Признаки подделки

  • Реклама внутри приложения — в оригинале её нет.
  • Просит войти через Google, номер телефона или оплатить «премиум».
  • Скачано не с GitHub и не с этого сайта: из чатов, «зеркал», магазинов.
  • Android при обновлении пишет «конфликт пакетов» — значит, стоит копия с другой подписью.
